# AI-HealthBot 🩺

**AI-HealthBot** is an intelligent healthcare and medical diagnosis assistant that enables users to input symptoms, ask health-related questions, and receive structured, evidence-based recommendations.

---

## 🌟 Key Features

- **Interactive Medical Query Interface**: Fast, responsive chat UI for symptom analysis.
- **Structured Clinical Recommendations**: Generates possible condition analysis, precautions, recovery guidance, and activity recommendations.
- **Provider-Agnostic AI Pipeline**: Powered by LangChain and high-speed LLM inference.
- **Safety Disclaimers & Red-Flag Warnings**: Built-in triage protocols advising when to seek immediate emergency medical care.

---

## 🛠️ Tech Stack

- **Backend**: Python, Flask / Streamlit
- **AI Framework**: LangChain
- **LLM**: Groq (LLaMA 3.3) / OpenAI
- **Environment**: python-dotenv

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rishabhkumar060/AI-HealthBot.git
cd AI-HealthBot
```

### 2. Create a virtual environment
```bash
python -m venv venv
```
Activate on Windows:
```powershell
venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the application
```bash
python app.py
```
